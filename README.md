## Projects

### Friendship Calculator

A simple command-line program that gives two people a friendship compatibility score based on a few questions.

Features:

- Friendship compatibility score
- Conversation compatibility
- Humor compatibility
- Shared activities
- Trust level
- Chaos level
- Different results based on the final score

Run it with:

```bash
python friendship.py
